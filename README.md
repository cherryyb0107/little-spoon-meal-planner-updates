# 작은 한 끼

월령별 이유식 레시피를 찾아 점심·저녁·간식으로 나누고, 직접 달력에 담아 쓰는 Windows 앱입니다. 레시피 카드의 사진과 조리 정보는 Cooking for my baby 원문 페이지를 참고합니다.

## 자동 업데이트

앱은 공개 Releases 저장소 `cherryyb0107/little-spoon-meal-planner-updates`에서 업데이트를 확인합니다. 처음 업데이트 기능이 포함된 버전을 설치한 뒤에는, 새 버전이 배포될 때 앱에서 다운로드하고 재시작해 적용할 수 있습니다. 아기 정보와 식단은 Windows 사용자 데이터 폴더에 저장되어 앱 업데이트와 별도로 유지됩니다.

새 버전은 `v2.0.4` 같은 버전 태그를 push하면 GitHub Actions가 Windows 설치 파일과 자동 업데이트 메타데이터를 빌드해 Releases에 게시합니다. 단계별 안내는 [UPDATE.md](UPDATE.md)를 참고하세요.
